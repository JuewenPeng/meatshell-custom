# v0.6.2-custom.3

## 中文

### 问题修复

- 修复多 Tab 场景中，SFTP 工具栏的下载、移动和删除按钮在未选中文件时不显示的问题。

### 改进

- SFTP 目录树和文件列表支持可持久化的“目录列表斑马纹”开关。
- 调整白色、黑色和江南主题的目录备用行背景色。
- 优化侧边停靠 SFTP 工具栏：路径框优先收缩；上级目录和刷新位于路径框左侧，在空间不足时与收起按钮一起跟随右侧拖动条；其余操作按优先级直接隐藏。
- 将侧边停靠 SFTP 面板的最小宽度调整为 250px，避免工具栏控件重叠。

## English

### Bug Fixes

- Fixed the SFTP toolbar Download, Move, and Delete buttons disappearing in multi-tab scenarios when no file is selected.

### Improvements

- Added a persistent “Directory list zebra stripes” setting for the SFTP directory tree and file list.
- Refined alternate directory-row colors for the Light, Dark, and Jiangnan themes.
- Improved the side-docked SFTP toolbar: the path field yields space first; Parent Directory and Refresh stay to its left, then follow the Collapse button and right-side splitter when space runs out; lower-priority actions hide in order.
- Raised the minimum side-docked SFTP panel width to 250px to prevent toolbar controls from overlapping.
