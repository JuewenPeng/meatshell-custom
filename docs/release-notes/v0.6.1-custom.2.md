# v0.6.1-custom.2

## 中文

### 新功能
- SFTP 内容区新增鼠标侧键目录导航，支持后退和前进。
- 每个会话新增最多 20 条纯路径目录历史记录。

### 改进
- 普通进入目录会写入后退历史并清空前进历史；后退、前进和刷新不会新增历史记录。
- 大目录加载期间会合并连续积压的目录跳转和刷新请求，只执行最后一次。
- 当目标目录不在目录树可视范围内时，自动展开并定位到可视区域约 `1/5` 的位置。
- 调整 SFTP 工具栏中“上级目录”按钮的位置，并优化目录树和文件列表中“加载全部”的文字对齐。
- 移除 SFTP 右侧文件列表的横向滚动条，保留纵向滚动和超出面板范围内容的裁切。
- 名称列表头拖动上限会为右侧列保留空间，并在窗口缩小时同步收紧列宽。
- 首次使用时，快速连接和运行状态面板默认停靠在左侧。

### 问题修复
- 修复手动滚动目录树后点击节点时，列表视口会产生额外偏移的问题。
- 修复目录树刷新时重建列表模型导致滚动位置不稳定的问题。

## English

### New Features
- Added mouse side-button navigation for SFTP directories, with back and forward support.
- Added per-session directory history with up to 20 path-only entries.

### Improvements
- Normal directory navigation records back history and clears forward history; back, forward, and refresh actions do not add history entries.
- During large-directory loading, consecutive queued navigation and refresh requests are coalesced so only the latest request runs.
- When the target folder is outside the directory-tree viewport, it is expanded and positioned at roughly one fifth of the visible area.
- Repositioned the SFTP parent-directory button and improved `Load all` text alignment in both the directory tree and file list.
- Removed the horizontal scrollbar from the SFTP file list while preserving vertical scrolling and clipping content beyond the panel boundary.
- The Name column resize limit now preserves space for right-side columns and contracts with the window when it is resized smaller.
- On first use, the Quick Connect and Resource Status panels default to the left side.

### Bug Fixes
- Fixed an extra directory-tree viewport offset after manually scrolling and then clicking a node.
- Fixed unstable directory-tree scroll positions caused by recreating the list model during refresh.
