# v0.6.1-custom.2

## 中文

### 新功能
- 新增终端状态栏显示开关，可在运行状态侧栏中切换，设置会自动保存。
- SFTP 内容区新增鼠标侧键目录导航，支持后退和前进。
- 每个会话新增最多 20 条纯路径目录历史记录。
- Tab 过多时可在 Tab 上滚动鼠标滚轮横向浏览，并显示可拖动的底部横向滚动条。

### 改进
- Tab 拖曳改为在松开鼠标后完成排序，避免拖动期间重建 Tab 导致交互不稳定。
- 普通进入目录会写入后退历史并清空前进历史；后退、前进和刷新不会新增历史记录。
- 大目录加载期间会合并连续积压的目录跳转和刷新请求，只执行最后一次。
- 当目标目录不在目录树可视范围内时，会自动展开并定位到可视区域约 `1/5` 的位置。
- 调整 SFTP 工具栏中“上级目录”按钮的位置，并为目录树和文件列表中的“加载全部”增加下载图标提示。
- 移除 SFTP 右侧文件列表的横向滚动条，保留纵向滚动和超出面板范围内容的裁切。
- 名称列表头拖动上限会为右侧列保留空间，并在窗口缩小时同步收紧列宽。
- 调整 SFTP 目录树和名称列的默认宽度，使初始文件浏览布局更均衡。
- 首次使用时，快速连接和运行状态面板默认停靠在左侧。
- SFTP 右侧文件列表取消 500 条首屏限制，目录内容会一次完整显示，不再显示“加载全部”。
- 名称排序改为普通字典序，例如 `10K`、`11K` 会排在 `1K`、`2K` 之前。
- 左侧目录树默认显示 30 个子目录；加载全部后可通过“⏫收起”恢复默认显示数量。
- SFTP 前进和后退历史会同时恢复对应目录的选中文件和滚动位置。
- Tab 宽度按实际标题文字计算，最大限制为 `250px`；超出的标题显示省略号。
- 统一 Tab 标题字号、关闭按钮、新建 Tab 按钮与图标字体，改善对齐与显示一致性。

### 问题修复
- 新标签页使用与普通 Tab 一致的标题布局和关闭按钮；关闭后仍可通过新建按钮重新打开。
- 修复手动滚动目录树后点击节点时，列表视口会产生额外偏移的问题。
- 修复目录树刷新时重建列表模型导致滚动位置不稳定的问题。
- 修复 Tab 栏滚轮支持影响右键菜单及关闭按钮点击的问题。

## English

### New Features
- Added a persistent terminal-status-bar visibility toggle in the Resource Status sidebar.
- Added mouse side-button navigation for SFTP directories, with back and forward support.
- Added per-session directory history with up to 20 path-only entries.
- Overflowing tabs can be browsed horizontally with the mouse wheel and a draggable bottom scrollbar.

### Improvements
- Tab reordering now completes on mouse release, avoiding unstable interaction caused by rebuilding tabs during a drag.
- Normal directory navigation records back history and clears forward history; back, forward, and refresh actions do not add history entries.
- During large-directory loading, consecutive queued navigation and refresh requests are coalesced so only the latest request runs.
- When the target folder is outside the directory-tree viewport, it is expanded and positioned at roughly one fifth of the visible area.
- Repositioned the SFTP parent-directory button and added a download icon indicator to `Load all` in both the directory tree and file list.
- Removed the horizontal scrollbar from the SFTP file list while preserving vertical scrolling and clipping content beyond the panel boundary.
- The Name column resize limit now preserves space for right-side columns and contracts with the window when it is resized smaller.
- Adjusted the default widths of the SFTP directory tree and Name column for a more balanced initial file-browsing layout.
- On first use, the Quick Connect and Resource Status panels default to the left side.
- Removed the 500-entry initial limit from the SFTP file list. Directories now display their complete contents without a `Load all` row.
- Changed Name sorting to regular lexicographic order; for example, `10K` and `11K` sort before `1K` and `2K`.
- The SFTP directory tree now initially shows 30 children. After loading all children, `⏫ Collapse` restores the default count.
- SFTP back and forward history now restores the selected file and scroll position for each directory.
- Tab widths are calculated from the rendered title, capped at `250px`, and elided when necessary.
- Unified tab title sizing, close/new-tab icons, and icon fonts for more consistent alignment.

### Bug Fixes
- New Tab now uses the same title layout and close button as regular tabs; it can still be opened again with the new-tab button after closing it.
- Fixed an extra directory-tree viewport offset after manually scrolling and then clicking a node.
- Fixed unstable directory-tree scroll positions caused by recreating the list model during refresh.
- Fixed tab-bar wheel scrolling interfering with right-click menus and close-button clicks.
