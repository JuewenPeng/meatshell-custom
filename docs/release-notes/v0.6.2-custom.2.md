# v0.6.2-custom.2

## 中文

### 新功能
- 本地 PowerShell 和 CMD 对应的右侧 SFTP 展开按钮也会禁用。
- 运行状态信息仅在运行状态面板可见时采样；面板隐藏后暂停采样，重新显示时自动恢复。
- 运行状态面板新增远程 NVIDIA GPU 显存监控：自动列出全部 GPU，并显示每张卡的显存已用/总量。

### 改进
- SFTP 删除按钮的提示框使用与悬停背景一致的实色红色，并通过主题颜色混合公式计算，避免透明度造成色差。
- Tab 正常悬停和点击时保持手形光标；开始拖曳后恢复默认光标形态。
- 完善 System Information 窗口的江南主题同步、中英文文案、外层边框和固定列布局。

### 问题修复
- 修复在 Tab 上短距离快速拖曳并松开时，蓝色拖放插入指示线残留的问题。
- 修复 SFTP 工具栏提示框坐标错误、显示位置整体偏移的问题。
- 修复 System Information 按钮在默认纵向运行状态面板中无法打开的问题。
- 修复 System Information 概览与表格列受文字长度影响而错位的问题。

## English

### New Features
- The SFTP expand button of Local PowerShell and CMD sessions is disabled.
- Resource status is sampled only while the Resource Status panel is visible; sampling pauses when the panel is hidden and resumes when it is shown again.
- Added remote NVIDIA GPU memory monitoring to Resource Status: every detected GPU is listed with used and total VRAM.

### Improvements
- The SFTP delete tooltip now uses the same solid red as its hover background, calculated with the theme color-mixing formula rather than transparency.
- Tabs retain a pointer cursor for normal hover and clicks, and return to the default cursor while being dragged.
- Improved the System Information window with Jiangnan-theme synchronization, Chinese/English text, an outer border, and fixed column layouts.

### Bug Fixes
- Fixed a blue tab drop insertion indicator remaining after a very short drag followed by a quick mouse release.
- Fixed SFTP toolbar tooltips being offset because their coordinates were calculated in the wrong coordinate space.
- Fixed the System Information button not opening from the default vertical Resource Status panel.
- Fixed System Information overview and table columns drifting with different text lengths.
