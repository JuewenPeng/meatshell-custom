# v0.6.3-custom.1

## 中文

### 改进

- 终端光标在文本输入或使用导航键移动时保持常亮 1 秒；停止操作后从亮态重新开始闪烁。
- 单独按下 Shift、Ctrl、Alt、Meta、Caps Lock 等修饰或锁定键不会触发光标常亮延时。
- 未聚焦的终端以与实心光标同尺寸的空心方块显示光标位置。

## English

### Improvements

- The terminal cursor stays solid for one second while typing or moving with navigation keys, then restarts its blink cycle from the visible phase.
- Standalone modifier and lock keys, such as Shift, Ctrl, Alt, Meta, and Caps Lock, do not trigger the cursor-visible delay.
- Unfocused terminals show the cursor location as a hollow block with the same size as the focused solid cursor.
